# 待测试

- JuxFlow ACS 更新已完成：健康接口、主要页面和 39 个 JS/CSS 资源可访问，Chrome 中已确认首页、画布列表的新品牌和导演台 GitHub 入口移除；完整主题、插件连接、创建与导出交互仍按下列事项验收。镜像及备份记录见 [部署说明](../overview/aliyun-acs.md)。
- JuxFlow 品牌：浏览器标题、导航、登录页无障碍标签、管理后台、画布列表、插件展示名与连接说明使用新名称；浅色、深色和窄屏布局正常。
- 画布命名与导出：各入口新建画布及默认导出文件名使用 JuxFlow，沿用现有编号规则；已有项目和自定义名称保留，导入导出与本地保存正常。
- 项目入口清理：普通页面、画布和管理后台不再显示项目 GitHub 按钮、版本号或版本说明，加载页面不再请求上游 VERSION、CHANGELOG；配置、主题切换和账户菜单正常。
- 3D 导演台：已局部移除现有打包文件中的 GitHub 按钮，打开、关闭、场景操作及截图回传正常；后续替换导演台产物时需继续保留这一修改。

- 阿里云 OSS 后台统一配置：官方 SDK 上传、流式和 Range 下载、中文文件名、删除、分页容量统计、保存后密钥脱敏及留空沿用。
- MySQL 初始化：唯一索引字段指定长度，设置表查询通过 GORM 转义保留字；生成任务及调用日志的请求/响应使用长文本，避免带参考图的请求超过 64 KiB 后保存失败。
- MySQL 大 JSON 同步：用户配置、素材、图片历史、视频/图片成果记录及工作流超过 64 KiB 时应完整保存；画布刷新及第二台设备读取正常。
- ACS 部署：单副本、独立数据库账号、私有 OSS、持久化数据卷、HTTPS 入口、原应用路由和 Pod 重建后数据保持。实际上线验证结果见部署说明。
- 运维配置：证书自动续期与受限 Secret 更新、SLS 标准输出和文件日志、可用性/重启/内存/磁盘告警及本项目备份脚本；告警接收人、专用只读 GHCR 凭证及数据库精细授权仍见 TODO。
- 云端接口验收已通过大 JSON、OSS 媒体与 Range、Pod 重建持久化；仍需第二台真实设备同步、浏览器视频拖动、真实模型生成和备份恢复演练。
